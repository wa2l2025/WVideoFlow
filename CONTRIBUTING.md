# Contributing to WVideoFlow 🎬

Thank you for your interest in contributing to **WVideoFlow**! We welcome contributions from developers, video editors, and open-source enthusiasts.

---

## 🛠️ How to Contribute

1. **Fork the Repository** to your GitHub account.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/your-username/WVideoFlow.git
   cd WVideoFlow
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/amazing-feature
   ```
4. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
5. **Test Your Changes**:
   ```bash
   python3 -c "import ast; ast.parse(open('app.py').read())"
   python3 app.py
   ```
6. **Commit & Push**:
   ```bash
   git commit -m "feat: add amazing new feature"
   git push origin feature/amazing-feature
   ```
7. **Open a Pull Request** against the `main` branch.
